# Humbl Pilates

Frontend for [humblpilates.com](https://humblpilates.com), a boutique reformer Pilates studio in Pererenan, Bali.

Next.js (App Router, JavaScript), GSAP + ScrollTrigger and plain CSS. There is no backend: booking, payment and the timetable stay on [Rezerv](https://humbl-pilates.rezerv.co).

## Run locally

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
```

## Structure

- `app/`: routes (`/`, `/classes/`, `/pricing/`, `/about/`), global styles, metadata, sitemap and robots
- `components/`: header, footer, closing band, photo frame, level tabs, price calculator, FAQ, motion
- `lib/content.js`: all copy, prices and links, taken from the Phase 1 audit
- `public/images/`: web-ready WebP photos (generated by `scripts/optimize-images.py`)
- `docs/IMPLEMENTATION.md`: build notes, verification and open client questions

Content marked `VERIFY` in `lib/content.js` still needs confirmation from the studio.
